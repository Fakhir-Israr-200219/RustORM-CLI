ARCHITECTURE DECISION (UNCHANGED)
─────────────────────────────────────────────

RustORM-CLI and the RustORM runtime remain separate projects.

RustORM-CLI is responsible for:

    rust.schema
        ↓
    Lexer
        ↓
    Parser
        ↓
    Schema AST
        ↓
    Validator
        ↓
    Code generators
        ↓
    CLI commands / project integration
        ↓
    Migration execution (--apply)
        ↓
    Configuration (.env / config.toml)

The CLI must not reimplement the RustORM runtime.

The generated code targets the existing RustORM runtime API.


                 rust.schema
                     │
                     ▼
                  Parser
                     │
                     ▼
              Schema Metadata
                 /       \
                /         \
               ▼           ▼
        Entity Generator   Migration Generator
               │           │
               ▼           ▼
          .rustorm/      .rustorm/
          generated/     migrations/
               │           │
               ▼           ▼
        User's Rust App ←──┘
               │
               ▼
          rustorm APIs
               │
               ▼
          RustORM Runtime
          / Query Engine
               │
              ┌┴──────────┐
              ▼           ▼
            Query       CRUD     Relations
              │
              ▼
            SQLx
              │
              ▼
          PostgreSQL

CURRENT PAUSE
─────────────
InsertData generation is intentionally paused.

Reason:
The runtime RustORM BindValue currently supports only:

    String(String)
    I64(i64)

The CLI schema supports additional scalar types and nullable values,
so completing InsertData generation now would make the generator depend
on an incomplete runtime binding layer.

Next work should therefore happen in the RustORM runtime:

    BindValue expansion
        ↓
    Executor binding support
        ↓
    Runtime tests
        ↓
    Return to CLI
        ↓
    InsertData generation
        ↓
    Update structs
        ↓
    UpdateData generation


IMPORTANT ARCHITECTURE DECISION
───────────────────────────────
RustORM-CLI and the RustORM runtime remain separate projects.

RustORM-CLI is responsible for:

    rust.schema
        ↓
    Lexer
        ↓
    Parser
        ↓
    Schema AST
        ↓
    Validator
        ↓
    Code generators
        ↓
    CLI commands / project integration

The CLI must not reimplement the RustORM runtime.

The generated code should target the existing RustORM runtime API.
